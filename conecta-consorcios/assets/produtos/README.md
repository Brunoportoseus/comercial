# Imagens dos produtos (tipos de consórcio)

Enquanto não houver foto, cada card mostra uma ilustração (SVG). Ao colocar
um arquivo aqui com o nome correspondente, a página passa a usar a **foto**
automaticamente (a ilustração some). Ver `initLogos` em `js/main.js`.

Formatos: `.jpg`, `.png` ou `.webp` (proporção ~16:9; a imagem é recortada
para preencher o card).

| Card | Nome do arquivo |
|---|---|
| Consórcio de Imóveis | `imoveis.jpg` (ou `.png`/`.webp`) |
| Consórcio de Veículos | `veiculos.jpg` |
| Consórcio de Serviços | `servicos.jpg` |
| Eletrodomésticos e Móveis | `moveis.jpg` |
| Consórcio de Agronegócio | `agro.jpg` |

⚠️ Use apenas imagens próprias ou de banco com licença adequada — não usar
fotos aleatórias da internet.
