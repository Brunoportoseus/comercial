# Logo — Consórcio Servopa (opcional)

Coloque aqui o logo do Consórcio Servopa. O slot no rodapé ("Produtos
administrados por") fica **oculto** até o arquivo existir.

Basta **um arquivo** (colorido, com fundo transparente de preferência):
`servopa.svg` (ideal) · `servopa.png` · `servopa.webp`

Ele é exibido sobre um "chip" branco, então o arquivo colorido fica legível —
não é preciso versão branca.

⚠️ **Autorização de marca:** só publique o logo da Servopa com autorização
de uso da marca. Não redesenhe nem recrie a marca — use o arquivo oficial.
