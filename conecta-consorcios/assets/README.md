# Assets — Conecta Consórcios

Substitua os **placeholders** por arquivos oficiais antes de publicar.
Não redesenhe, distorça ou recrie a marca — use os arquivos fornecidos pela empresa.

| Arquivo | Uso | Situação |
|---|---|---|
| `logos/conecta/` | Logo da Conecta (cabeçalho + rodapé) | 📁 Coloque os arquivos oficiais aqui — ver `logos/README.md` |
| `logos/servopa/` | Logo do Consórcio Servopa (rodapé, opcional) | 📁 Coloque o arquivo aqui (com autorização de marca) |
| `logo-placeholder.svg` | Placeholder do cabeçalho enquanto não há logo | ⚠️ Substituído automaticamente ao adicionar o logo em `logos/conecta/` |
| `logo-placeholder-negativo.svg` | Placeholder do rodapé enquanto não há logo | ⚠️ Substituído automaticamente ao adicionar o logo em `logos/conecta/` |
| `favicon.svg` | Ícone da aba do navegador | ⚠️ Temporário/abstrato — substituir pelo oficial |
| `og-card.jpg` | Imagem de compartilhamento (Open Graph 1200×630) | ❌ Ausente — criar com imagem/licença adequada |

**Não é preciso editar o HTML para trocar os logos:** basta colocar os arquivos
em `logos/conecta/` (e `logos/servopa/`) com os nomes esperados — a troca é
automática (ver `logos/README.md`).

Imagens institucionais (seção "Sobre") devem vir de arquivos oficiais ou de
banco de imagens com licença adequada — nunca imagens aleatórias da internet.
