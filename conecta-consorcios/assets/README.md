# Assets — Conecta Consórcios

Substitua os **placeholders** por arquivos oficiais antes de publicar.
Não redesenhe, distorça ou recrie a marca — use os arquivos fornecidos pela empresa.

| Arquivo | Uso | Situação |
|---|---|---|
| `logo-placeholder.svg` | Logotipo no cabeçalho (fundo claro) | ⚠️ Placeholder — substituir por `logo.svg` oficial |
| `logo-placeholder-negativo.svg` | Logotipo no rodapé (fundo escuro) | ⚠️ Placeholder — substituir pela versão negativa oficial |
| `favicon.svg` | Ícone da aba do navegador | ⚠️ Temporário/abstrato — substituir pelo oficial |
| `og-card.jpg` | Imagem de compartilhamento (Open Graph 1200×630) | ❌ Ausente — criar com imagem/licença adequada |

Ao trocar os logos, ajuste os caminhos em `index.html` (cabeçalho e rodapé) e nas páginas de `privacidade/` e `termos/`, se necessário.

Imagens institucionais (seção "Sobre") devem vir de arquivos oficiais ou de
banco de imagens com licença adequada — nunca imagens aleatórias da internet.
