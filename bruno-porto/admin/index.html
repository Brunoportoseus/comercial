Admin do Blog

Faça login com seu GitHub Personal Access Token (PAT) para gerenciar os posts.

Como criar um token:
1. Acesse github.com/settings/tokens
2. Clique em "Generate new token"
3. Em Repository access, selecione apenas Brunoportoseus/comercial
4. Em Permissions → Contents, marque Read and write
5. Copie o token (começa com github_pat_) e cole aqui

O token fica salvo só no seu navegador. Para sair, use o botão "Sair" no topo.
