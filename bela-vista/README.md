# Condomínio Bela Vista — Landing Page

Landing page de captação para o **Condomínio de Terrenos Bela Vista** (EVEX Imóveis),
na Região Norte de Curitiba.

## Estrutura
- `index.html` — página única (landing) com todas as seções do briefing.
- `assets/css/styles.css` — estilos.
- `assets/js/main.js` — pequenas interações (ano do rodapé, sombra da topbar).
- `assets/img/` — imagens extraídas do book de apresentação (`Bela_Vista_Book`)
  e logos da EVEX (`evex-logo.png`, `evex-logo-white.png`).

## Seções
1. Hero — título, subtítulo e CTAs.
2. O Empreendimento — infraestrutura pronta (paver, calçadas gramadas, iluminação).
3. Projeto / Masterplan.
4. Lazer & Recreação.
5. Localização privilegiada (endereço + tempos de deslocamento).
6. Condições de pagamento (tabela de preços e parcelas).
7. CTA final + rodapé.
