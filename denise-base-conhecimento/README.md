# Base de conhecimento — Studio Denise de Paula (IA Kommo)

PDF em formato **Perguntas e Respostas** para alimentar a IA de atendimento
automático do Kommo, para que ela responda às dúvidas das clientes.

## Arquivos
- `base-conhecimento-denise-de-paula-kommo.pdf` — documento final (7 páginas).
- `gerar_pdf.py` — gera/atualiza o PDF (`python3 gerar_pdf.py`, requer `reportlab`).

## Origem do conteúdo
Extraído do site oficial `micropigmentacaodenisedp.com.br`
(páginas: home, `/sobrancelhas`, `/denise-de-paula`, `/contato`), via busca web —
o acesso direto ao domínio está bloqueado pela política de rede deste ambiente.

## Pendências (marcadas como `[CONFIRMAR COM A DENISE]` no PDF)
Endereço completo, horários, tabela de preços, formas de pagamento, política de
retoque, tempo de cada procedimento, contraindicações oficiais, política para
grávidas/diabéticos e conteúdo do blog. Ao receber esses dados, editar o texto
correspondente em `gerar_pdf.py` e rodar o script novamente.
